# 📋 Planeacion de proyectos



## 7 pasos para planear y gestionar un proyecto para resultados exitosos

Estructura Desglosada del Trabajo (EDT / WBS)

1. **Alcance**. Se descompone el alcance del proyecto en entregables y paquetes de trabajo cada vez más manejables. Responde principalmente: “¿Qué hay que hacer?”. Es la base de los pasos posteriores porque permite identificar todo el trabajo necesario para lograr los resultados esperados.
2. **Cronograma del proyecto**. Se identifican y secuencian las actividades, se estiman sus duraciones, dependencias y fechas. Responde: “¿Cuándo se hará?”. Aquí se determina la lógica temporal del proyecto y pueden identificarse hitos y actividades críticas. Indes Virtual
3. **Curva S**. Representa gráficamente la utilización acumulada de recursos o costos a lo largo del tiempo. Permite comparar lo planificado con lo ejecutado y controlar el desempeño del proyecto. En otras palabras: “¿Cuánto deberíamos haber avanzado o gastado a esta fecha?”. Indes Virtual
4. **Matriz de adquisiciones**. Organiza los bienes, obras o servicios que deben contratarse o comprarse para ejecutar el proyecto. Determina qué se adquiere, cuándo se necesita y cómo debe integrarse con el cronograma. Responde: “¿Qué necesitamos adquirir para poder ejecutar el proyecto?”. Indes Virtual
5. **Matriz de riesgos**. Identifica acontecimientos inciertos que podrían afectar los objetivos del proyecto. Se analizan normalmente su probabilidad, impacto y respuesta prevista. Su pregunta central es: “¿Qué podría impedir o afectar el logro de los resultados y qué vamos a hacer frente a ello?”. Indes Virtual
6. **Matriz de comunicaciones**. Establece qué información necesita cada interesado, quién la genera, quién la recibe, mediante qué medio y con qué frecuencia. Responde: “¿Quién necesita saber qué, cuándo y cómo?”. Indes Virtual
7. **Matriz de Asignación de Responsabilidades (MAR / RAM)**. Relaciona los trabajos o entregables con las personas responsables de ejecutarlos. Busca eliminar ambigüedades respecto a autoridad y responsabilidad. Responde: “¿Quién es responsable de cada parte del proyecto?”.

Como se puede evidenciar el orden es el siguiente:

EDT $\rightarrow$ Cronograma $\rightarrow$ Curva S $\rightarrow$ Adquisiciones $\rightarrow$ Riesgos $\rightarrow$ Comunicaciones $\rightarrow$ Responsabilidades

Lo cual se puede simplificar en:

**Que hacer (alcance) $\rightarrow$ Cuando hacerlo $\rightarrow$ Cuantos recursos $\rightarrow$ Que comprar $\rightarrow$ Que puede salir mal $\rightarrow$ Como comunicar $\rightarrow$ Quien hace que**

Para poder usar claramente los 7 pasos en el orden establecido se debe tener **experiencia**, sin embargo, se puede cambiar este orden debido al desconocimiento del area o campo del proyecto. Por lo cual se debe tener conocimiento del desglose para poder entender cada particularidad de las fases o etapas.
