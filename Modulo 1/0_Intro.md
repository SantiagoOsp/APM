# Introducción Curso

## Modulos:

La siguiente es la distribucion del curso completo

- Automatizacion Transformacion digital industrial: Diseñar conceptial una arquitectura de automatizacion para un sistema productivo
- Gestion y evaluacion de la produccion: Aplicar conceptos de preautomatizacion y gestion de produccion mediante KPIs -> Para evaluar un proceso de produccion (Tecnomatix "Siemens")
- Planeacion y evaluacion de proyectos: Establecer un proyecto a partir del desglose de actividades y herramientas de planeacion, y hacer analisis de inversion a partir de indicadores economicos ("BID Banco Interamericano de Desarrollo" Planeacion de proyectos)
- Celdas de manufactura robotizadas: Diseñar celdas de manufactura celular basadas en robots, teniendo en cuenta integracion, elementos de proteccion y programacion de las tareas.
- Tecnologias modernas aplicadas a la manufactura: Aplicar gemelos digitales, comisionamiento virtual -> Integracion de produccion y automatizacion de la fabrica.
- Automatizacion discreta: PLC y SCADA: Diseñar e implementar estrategias de control regulatorio, logico-secuencial y supervision para sistemas industriales.

### Proceso continuo

Se manejan variables continuas, transformacion de productos fisico-quimicos. (4 hermanas industriales Pressure, Flow, Temperature, Level).

### Proceso discreto

Produccion, manufactura de unidades individuales.

### Proceso por lotes (Tipo batch)

Es el proceso "Intermedio" de uno discreto y uno continuo. Por ejemplo, el proceso de creacion de gaseosas donde primero se trabaja continuamente el producto para luego llevarse a un empaque.
